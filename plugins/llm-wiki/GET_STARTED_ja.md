# llm-wiki で Claude の回答をもっと役立つものにする

Claude に大切なドキュメントやメモを渡しておけば、必要なときにふつうの言葉で質問できます。新しく続けることはひとつだけです。覚えてほしい材料を wiki に追加します。

## こんなことはありませんか？

- 新しいチャットを開くたびに、同じ背景を説明し直している。
- 決定があったことは覚えているのに、メモ、ドキュメント、以前のチャットのどこにあるか分からない。
- 以前のファイルを探し回るのではなく、すでにある材料にもとづく明確な答えがほしい。

llm-wiki は、そうした散らばった材料を Claude が回答に使えるページへ変えます。

## 最初にすること

Claude に理解してほしいドキュメントをひとつ追加します：

```
/wiki-ingest-docs ./docs/customer-plan.md
```

たとえば顧客向けの計画を追加してから、*「この顧客について何をすることで合意した？」* と尋ねます。Claude は wiki をもとに答え、要点ごとにページパスを示すので、答えの出どころを確かめられます。

## 最初のドキュメントから役立つ答えまで

大切な顧客向け計画を Claude に最新の状態で理解させたい場面を考えます。

1. まず一度だけ `/wiki-init` を実行します。保存場所を尋ねられます。
2. `/wiki-ingest-docs ./docs/customer-plan.md` で計画を追加します。
3. 提案されたページ更新を確認し、問題なければ承認します。承認するまで何も保存されません。
4. いつもどおり作業を続けます。後で Claude に、計画に何が書かれているか、何を決めたかを尋ねます。
5. Claude が関連ページを読み、ページパスを添えて答えます。
6. その会話を残したければ `/wiki-file` を実行します — あるいは *「それをページとして保存して」* と言うだけでも構いません。Claude の結論は、あなたが昇格を選ぶまで、はっきり区別された状態で保存されます。
7. 次に答えが必要なときは、古いチャットから背景を組み立て直す代わりに、もう一度尋ねるだけです。

## Claude が知っていることを見る

次を実行します：

```
/wiki-view
```

`http://127.0.0.1:17330/` にローカルビューアが開きます。リンクされたページをたどり、それぞれが確立したソースページか、Claude のはっきり区別された結論かを確認できます。元のソース材料はビューアには表示されません。

## 操作の主導権はあなたにあります

- 質問は wiki を読むだけで、内容は変わりません。
- 通常の取り込みでページが書かれる前には、確認と承認があります。
- 取り込みの途中で失敗した場合、その変更は元に戻ります。

## 今すぐ始める

Claude Code にプラグインをインストールします：

```
/plugin marketplace add gigamori/ai-agent-toolkit
/plugin install llm-wiki@ai-agent-toolkit
```

PATH に [`uv`](https://docs.astral.sh/uv/) があることを確認し、次を実行します：

```
/wiki-init
```

Claude に理解してほしいドキュメントをひとつ追加してみてください。詳しい手順は [ユーザーガイド](USER_GUIDE_ja.md) を参照してください。
