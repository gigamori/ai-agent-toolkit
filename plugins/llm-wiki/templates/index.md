# Index

Content-oriented catalog of this wiki. Organize entries by topic/subject (what a
page is ABOUT), not by ingest order or file mechanics. The catalog is read
directly; at scale (~100 sources) an optional qmd layer may be introduced.

Pages live in `wiki/` (source tier) and `wiki/derived/` (derived tier). Citation
is by path, and the path expresses the tier — `wiki/` entries are source-tier,
`wiki/derived/` entries are derived-tier (code adds the tier marker from the path;
no new LLM rule).
