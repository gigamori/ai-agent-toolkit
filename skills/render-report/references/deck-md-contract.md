# Deck Spec Contract

pptx 経路の中間正本 **deck-spec** の構造契約。report.md（[report-md-contract.md](report-md-contract.md) 準拠）を媒体向けに再著述した結果を、機械検査できる形で固定する。

deck-spec は report.md を置き換えない。report.md が内容の正本、deck-spec はデッキ 1 本ぶんの正本であり、媒体都合の短縮はすべて deck-spec 側で行う。

決定論チェック: `scripts/validate_deck.py`（G-A）
LLM チェック: [deck-review.md](deck-review.md)（G-B）

## Frontmatter（必須）

```yaml
---
source: "final_report.md"
title: "<report.md の title 原文>"
---
```

| キー | 必須 | 値 |
|------|------|-----|
| `source` | 必須 | 由来した report.md のファイル名またはパス |
| `title` | 必須 | report.md の frontmatter `title` の**原文**。再著述しない |

値はすべてダブルクオートで囲む。

## スライド

1 スライド = `## S<n> <原型>` 見出し 1 つ。`<n>` は 1 から始まる連番で、欠番・重複・順序の入れ替えを許さない。

```markdown
## S5 finding
trace: F-1
- headline: 申込率の変動は接触時期に支配される
- confidence: ○ 小規模試行を推奨できる強さ
- body: ...
- evidence: ...
```

見出しの直後の行に `trace:` を置く（`title` 原型を除く。後述）。以降は `- <スロット名>: <値>` の行、GFM テーブル、チャートアノテーションを任意の順で並べる。

スロット値が複数行にわたる場合、2 行目以降はインデントせずそのまま続ける（次の `- <スロット名>:` 行、テーブル、見出しまでが 1 スロットの値）。

## 原型（6 種）

| 原型 | 用途 | 必須スロット | 任意スロット |
|------|------|-------------|-------------|
| `title` | 表紙 | なし | なし |
| `exec-summary` | エグゼクティブサマリ | `message` / `findings` / `limits` | `notes` |
| `section` | 分析対象データ・データの基本的特徴・限界と注意事項 | `headline` / `body` | `table`（GFM テーブルとして置く）/ `notes` |
| `finding` | 発見事項 1 件 | `headline` / `confidence` / `body` / `evidence` | `limit`（条件付き必須。後述）/ `notes` |
| `evidence` | チャートと元表 | なし（テーブル 1 つ以上） | `notes` |
| `appendix` | 付録 | なし | `notes` |

原型は 6 種で閉じている。新しい原型を deck-spec 側で発明しない。

`本文スライド` = `exec-summary` / `section` / `finding` の 3 原型。G-B（忠実性ジャッジ）の対象はこの 3 原型に限る。`title` / `evidence` / `appendix` は対象外。

### スロットの意味

| スロット | 内容 |
|---------|------|
| `message` | エグゼクティブサマリの分析目的・位置づけ |
| `findings` | 主要な発見（report.md と同じ優先順、3 点以内） |
| `limits` | 主な限界 |
| `headline` | スライド 1 枚の主張。1 文。`finding` では report.md の `### [F-n]` 見出しの再著述を許可する（`[F-n]` は除去する） |
| `confidence` | `- 確信度:` の値。**記号 + 訳語を原文どおり**転記する |
| `body` | `- 解釈:` または `- 実務示唆:` の圧縮 |
| `evidence` | `- 根拠:` の数値。n と分母を落とさない |
| `limit` | `- 限界:` の圧縮 |
| `table` | 表の見出し。表そのものは同じスライドに GFM テーブルとして書く。値は表の上に描画されるので、空にしない |
| `notes` | 発表者ノート。デッキ本体に描画されない |

`finding` の `limit` は、その `trace` が指す report.md のクレームブロックに `- 限界:` が存在する場合に必須。存在しない場合は置かない。

## trace

`trace:` は `title` 原型を除く全スライドに必須。値は report.md の 1 箇所を指す。

| 値 | 指すもの |
|----|---------|
| `エグゼクティブサマリ` | `## エグゼクティブサマリ` |
| `分析対象データ` | `## 分析対象データ` |
| `データの基本的特徴` | `## データの基本的特徴` |
| `F-n` | `### [F-n] ...` のクレームブロック |
| `限界と注意事項` | `## 限界と注意事項` |
| `付録/<小見出し>` | `## 付録` 配下の `### <小見出し>` |

`title` 原型が trace を持たないのは、その内容が frontmatter の `title` / `source` によってすでに出所を固定されているため。

同じ trace を複数のスライドが持ってよい（1 節を 2 枚に割るのは通常の配置判断）。逆に、report.md 側の `[F-n]`・`エグゼクティブサマリ`・`限界と注意事項` はいずれも**本文スライドの trace に 1 回以上**現れなければならない（主張カバレッジ）。

## テーブル

テーブルの種別はマーカーではなく**ヘッダ行**で判別する。

- **source 表**: ヘッダ行が report.md のいずれかのテーブルのヘッダと一致する表。report.md のその表と**全行全列一致**でなければならない。行の間引き、列の削除、セルの言い換え、数値の再フォーマットをすべて禁止する。
- **authored 表**: それ以外の表。report.md の散文から著者が構成してよい。数値は出所検査（後述）のみを受け、文字列セルは G-B の判定対象となる。

セルの比較は前後の空白を落としたうえで行う。強調記号（`**`）は文字列の一部として扱う。

## チャート

```markdown
<!-- chart: bar x=期間 y=申込率 title="年別の申込率（分母=当年の案件）" -->

| 期間 | 案件数 | 申込件数 | 申込率 |
|---|---|---|---|
| 2008年 | 27,729 | 1,401 | 5.052 |
```

- アノテーション行は report.md の**注釈行と空白正規化後に一致**すること。新しいチャートを deck-spec 側で発明しない。
- アノテーションの次の非空行から GFM テーブルが始まり、そのテーブルは source 表であること。

## 数値の出所

本文中の数値トークンは、すべて report.md に実在する数値トークンでなければならない。

- 対象: スロット値、テーブルセル、チャートアノテーション。
- 対象外: 構造行（`## S<n> <原型>` 見出し、`trace:` 行、`- <スロット名>:` のスロット名部分、frontmatter）。
- 正規化は桁区切り（`,`）の除去と、トークン末尾の `.` の除去のみ。**単位や表記の変更（`45,211` → `4.5万`、`12.4%` → `約 1 割`）は原文転記違反**として扱う。

## 許可される省略と、許可されない省略

deck-spec は report.md の全文を運ばない。何を落としてよいかは [deck-authoring.md](deck-authoring.md) の生存規則が定義し、G-B が判定する。契約（本ファイル）が定めるのは構造だけである。

構造として落とせないもの:

- `finding` の `confidence`（記号 + 訳語、原文一致）
- `finding` の `evidence`（n と分母を含む数値）
- `exec-summary` の `limits`
- 主張カバレッジ（全 `[F-n]` / `エグゼクティブサマリ` / `限界と注意事項`）

## 禁止事項

| 禁止 | 理由 |
|------|------|
| report.md に無い数値トークン | 出所のない数値はデッキで検証できない |
| 数値の再フォーマット（丸め・単位変換・桁区切り変更） | 精度が静かに落ちる |
| source 表の行・列の間引き | 表として提示しながら中身が別物になる |
| report.md に無いチャートアノテーション | 図は宣言されたものからのみ生成される（report.md 側の契約と同じ） |
| `purpose: findings` の report.md に対する行動動詞 | report.md 側で禁じたものを媒体で復活させない |
| 6 原型以外の見出し | 配置（[deck-archetypes.md](deck-archetypes.md)）が解決できない |
