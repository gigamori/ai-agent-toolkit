# Deck Review

忠実性ジャッジ **[G-B]** の手順。deck-spec の本文スライドが report.md の主張を歪めずに運んでいるかを判定する。

fresh context で実行する。deck-spec を書いた [A] と同じコンテキストで実行してはならない（自分が書いたものを自分で採点することになる）。

## 立ち位置

**編集しない**。deck-spec も report.md も書き換えない。判定と所見だけを返す。

**可読性を評価しない**。読みやすいか、スライドとして良いかは人間の承認段 [H] の仕事。ここで見るのは意味の忠実性だけ。

## 入力

| 入力 | 範囲 |
|------|------|
| report.md | 全文 |
| deck-spec | **本文スライドのみ**（`exec-summary` / `section` / `finding`） |
| 本ファイル | 判定ルール |

専用の抽出スクリプトを使わない。report.md と deck-spec をそのまま読む。

## 照合対象外（指摘してはならない）

- `検証状態` — 本文スライドに載せない設計。その省略を逸脱として挙げない。
- `付録` — 対象外。
- `根拠` の数値の正誤 — G-A（`validate_deck.py`）が数値の出所を機械検査済み。数字が report.md に無いという指摘をしない。
- `title` / `evidence` / `appendix` スライド — 対象外。

## 生存規則

### 必ず残っていること（欠落は逸脱）

- エグゼクティブサマリの**主要な発見**と**主な限界**
- 各 `F-n` の見出しの主張、`確信度`、`解釈` または `実務示唆`、`限界`
- `限界と注意事項` のうち**標本独立性の違反開示**

### 統合を許す

- `限界と注意事項` のその他の項目。複数項目を 1 文に束ねることは許可する。ただし**項目の主張が消えていれば逸脱**。
- `検証状態` の詳細、頑健性チェックの変種列挙、節の導入文の省略は逸脱ではない。

## 逸脱分類（この 5 種で分類する。新しい種別を作らない）

| クラス | 内容 |
|--------|------|
| `MODALITY_UP` | 様相の強化・留保の削除。「排除できない」→「排除された」、「示唆」→「証明」、「参考値」→「結果」 |
| `QUALIFIER_DROP` | 分母・n・限界・確信度の脱落。生存規則で「必ず残す」としたものの欠落を含む |
| `UNTRACEABLE` | 本文スライドの文言が report.md 本文に帰着しない。report.md に無い主張・因果・含意の追加 |
| `EMPHASIS_SWAP` | 主結論の順序・強調の入替え。層別優越の逆転（統制後の値ではなく粗の値を主結論にする等）を含む |
| `CONTRADICTION` | スライド間の矛盾。同じ量に異なる値・異なる向きを与えている |

## 出力形式

先頭行に `PASS` または `FAIL` のみを置く。以降は所見の箇条書き。JSON にしない。

```
FAIL
- S5/headline MODALITY_UP F-2: <report 引用> → <deck 引用>
- S12/body QUALIFIER_DROP F-9: 分母=当該帯の案件 が落ちている
- S22/body QUALIFIER_DROP 限界と注意事項: 標本独立性の違反開示が消えている
```

各行は `- <スライド>/<スロット> <クラス> <trace>: <根拠>` の形で、report.md 側と deck 側の該当箇所を引用する。逸脱が 1 件でもあれば `FAIL`。0 件なら `PASS` の 1 行のみ。

推測で指摘しない。report.md の該当箇所を引用できない指摘は出さない。

## このジャッジが見ないもの

- `title` / `evidence` / `appendix` スライド
- 視覚的な強調（太字・配色・サイズ）による意味の変化
- 数値の正誤（G-A の担当）
- 確率的な取りこぼし — 同じ deck-spec を 2 回判定して同じ結果になる保証はない。検出率は逸脱クラスごとに計測した基準率でのみ語れる（[AUTHORING_CONTRACT.md](../../../docs/skills/render-report/AUTHORING_CONTRACT.md)）
