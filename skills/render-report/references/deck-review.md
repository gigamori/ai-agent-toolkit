# Deck Review

忠実性ジャッジ **[J]** の手順。生成された pptx のテキストが report.md の主張を歪めずに運んでいるかを判定する。

**省略は逸脱ではない。歪みだけを見る。** report.md の記述がデッキに無いこと自体は指摘の対象ではない。デッキに載っている文と数値が report.md の主張とずれているかだけを判定する。

fresh context で実行する。デッキを作った [D] と同じコンテキストで実行してはならない（自分が書いたものを自分で採点することになる）。

## 立ち位置

**編集しない**。pptx も report.md も書き換えない。判定と所見だけを返す。

**可読性を評価しない**。読みやすいか、スライドとして良いかは人間の承認段 [H] の仕事。ここで見るのは意味の忠実性だけ。

## 入力

| 入力 | 範囲 |
|------|------|
| report.md | 全文 |
| デッキのテキスト | `officecli view <pptx> text` の出力。スライドごとに `=== /slide[N] ===` で区切られている |
| report.md に無い数値の列挙 | `check_pptx_text.py` の出力。面上にあって report.md に無い数値トークンと、その行。装飾番号（区切りの `01`）もデータ値も区別なく並ぶ |
| 範囲 | [D] に渡された範囲指定があればそれ。範囲外の発見が無いことは指摘しない |
| 本ファイル | 判定ルール |

画像を受け取らない。専用の抽出スクリプトを使わない。report.md とテキスト出力をそのまま読む。

## 照合対象外（指摘してはならない）

- 列挙に無い数値の出所 — report.md にある数値は機械で確認済み。自分で数字を照合し直さない。
- 見せ方（カード・箇条・チャートのどれか、配置、色、太字）— [D] の領分であり、[H] が見る。
- `検証状態` や `付録` の省略。
- 表紙・目次・区切り・付録スライド。

## 何を探すか（5 つ。新しい種別を作らない）

デッキがレポートに対してやりがちなこと。**名前より、やっていることで探す。**

| やっていること | タグ |
|--------------|------|
| **言い過ぎている・煽っている。** 「排除できない」を「排除された」に、「示唆する」を「証明した」に、「参考値」を「結果」に。留保を外して強く言う | `OVERSTATED` |
| **都合の悪い条件を落としている。** 残した数値から分母や n が消えている。数値そのものを落としたこと、段落を落としたことは対象外 | `CAVEAT_DROPPED` |
| **作り話をしている。** レポートに無い主張・因果・含意・数値を足している。もっともらしいが、レポートのどこにも書いていない。列挙された数値のうち、率・件数・差・比のようなデータ値はこれ（区切りの `01` のような装飾番号は違う） | `FABRICATED` |
| **都合よく切り取っている。** 主結論の順序を入れ替える、弱い所見を前に出す、統制後ではなく粗の値を主結論に置く | `CHERRY_PICKED` |
| **矛盾している。** スライド間で同じ量に違う値・違う向きを与えている | `CONTRADICTION` |

## 出力形式

先頭行に `PASS` または `FAIL` のみを置く。以降は所見の箇条書き。JSON にしない。

```
FAIL
- slide 5 OVERSTATED F-2: <report 引用> → <deck 引用>
- slide 12 CAVEAT_DROPPED F-9: 分母=当該帯の案件 が落ちている
- slide 22 CHERRY_PICKED F-4: 統制後の値ではなく粗の値を主結論に置いている
```

各行は `- slide <N> <クラス> <F-n>: <根拠>` の形で、report.md 側と deck 側の該当箇所を引用する。逸脱が 1 件でもあれば `FAIL`。0 件なら `PASS` の 1 行のみ。

推測で指摘しない。report.md の該当箇所を引用できない指摘は出さない。

## このジャッジが見ないもの

- 視覚的な強調（太字・配色・サイズ）による意味の変化
- チャートの描かれ方（系列の選び方、軸の切り方）
- report.md にある数値の正誤（同じ数字が別の量に付け替えられていても、列挙には出ない）
- 確率的な取りこぼし — 同じデッキを 2 回判定して同じ結果になる保証はない。検出率は逸脱クラスごとに計測した基準率でのみ語れる（[AUTHORING_CONTRACT.md](../../../docs/skills/render-report/AUTHORING_CONTRACT.md)）
